### About Me

I'm a Computer Science graduate and Software Engineer passionate about building secure, scalable, and maintainable software.

I enjoy turning ideas into real products, designing reliable backend systems, building intuitive user experiences, and continuously learning how software works at scale. I'm particularly interested in fullstack engineering, system design, APIs, databases, cloud infrastructure, and developer tooling.

- Based in **Lagos**
- Building with TypeScript, JavaScript, Node.js, React, and Next.js
- Experienced in building REST APIs, authentication systems, and database-driven applications
- Working with PostgreSQL, MongoDB, and Prisma
- Deploying applications with AWS (EC2, ECR, CloudWatch)
- Building and running applications with Docker & containers
- Interested in secure authentication, authorization, performance, and reliable system design
- I love turning ideas into products that are built to last

### What I Care About

#### Full-Stack Engineering
Building complete products from intuitive, responsive interfaces to secure, reliable backend systems, with a focus on writing software that's maintainable and built to scale.

#### Frontend Engineering
Creating modern, accessible, performant user interfaces with thoughtful interactions, animations, and attention to the details that make products feel great to use.

#### Backend Engineering
Designing robust APIs, authentication systems, database architectures, and business logic that are secure, reliable, performant, and easy to maintain.

#### System Design
Understanding how different components work together to build reliable systems that can evolve as requirements and users grow.

#### Cloud & Infrastructure
Deploying, containerizing, and operating applications using cloud infrastructure, Docker, reverse proxies, and modern deployment practices.

#### Product Engineering
I care about more than just making software work. I enjoy understanding the problem, thinking through the trade-offs, and building products that solve real problems well.
